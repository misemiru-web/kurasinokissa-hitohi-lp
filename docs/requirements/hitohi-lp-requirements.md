# 4. 仮説・未確認事項

## 4-1. 仮説

- 店舗価値の中心は、飲食単体ではなく「佐潟の自然のそばで、食・休息・手仕事を楽しむ時間」にある。

- Instagramの写真・コピーから、強い広告感よりも、自然体・静けさ・手作り感・地域とのつながりを重視するブランド印象がある。

- 初回来店者には、メニューだけでなく「佐潟と一緒にどう過ごせるか」を見せることで店舗固有性が伝わりやすい。

- ワークショップ・イベントは、来店理由を増やす補助価値として有効。ただしカフェの基本情報より前面に出しすぎない。

# 5. 店舗分析

## 5-1. 特徴

1. 佐潟公園前という、自然環境が明確に感じられる立地。

2. 薪窯パン舎ほほのパンを使ったサンドを中心に、スープ・野草茶・コーヒー・スイーツ等を展開。

3. 季節の手仕事や藤編み等、暮らしに接続するワークショップを開催。

4. 佐潟の風景・植物・自然素材と調和した、素朴でやわらかなビジュアル表現。

5. 店内では生活雑貨等も見られ、飲食だけに閉じない暮らしの提案性がある。

## 5-2. LP上で優先する強み

| 優先 | 強み | ユーザー価値 | 表現方針 |
| --- | --- | --- | --- |
| 1 | 佐潟公園前 | 来店そのものを自然散策と一緒に楽しめる | Heroと佐潟セクションで大きく見せる |
| 2 | ほほのパンを使うサンド | 何を食べられる店か具体的に理解できる | 商品写真を大きく。製法はほほ公式情報の範囲で補助。 |
| 3 | 食＋手仕事＋自然 | 普通のカフェより幅広い過ごし方が想像できる | Workshopは中盤以降で紹介 |
| 4 | 静かな店舗世界観 | 初訪問時の心理的ハードルを下げる | 余白・自然色・実写真中心 |

## 5-3. 提供価値・差別化仮説

> **提供価値（仮説）**
> 佐潟の自然を身近に感じながら、食べる・休む・手を動かす時間を日常の延長として楽しめること。

競合調査を実施していないため、「他店より優れている」「新潟で唯一」等の比較優位は断定しない。差別化は店舗固有の組み合わせを整理して見せる。

1. 数秒で「佐潟公園前の小さなカフェ」と分かる。

3. 佐潟と一緒に過ごすイメージが伝わる。

4. ワークショップ等の店らしさが分かる。

5. 営業日・アクセスの確認方法が迷わず分かる。

# 8. LP・デザインコンセプト

## 8-1. メインメッセージ

> **仮H1**
> 佐潟のほとりで、食と自然と暮らしを楽しむ。

上記は営業サンプル用の仮コピー。公式の理念として断定せず、正式制作時に店舗の言葉へ調整する。

## 8-2. ブランドトーン

- 自然体、静けさ、手仕事、地域性、あたたかさ。

- 「健康」「癒やし」を過度に効能表現へ寄せない。体験としての心地よさを表現する。

- 大企業的な広告バナー感、強いセールスコピー、派手なグラデーションは避ける。

- Instagramで見られる手書き文字・クラフト感は、ロゴと細線・紙質感程度に抑えてWebとして整える。

## 8-3. 仮デザインシステム

| 要素 | 仮指定 | 用途 |
| --- | --- | --- |
| Background | #F5F1E8 | 生成り。ページの基本背景。 |
| Surface | #FFFFFF | 情報カード・写真周辺。 |
| Primary | #465646 | 落ち着いた植物系グリーン。CTA・見出し。 |
| Text | #2F352F | 黒より柔らかい濃色。 |
| Sub text | #6F716D | 補足・注釈。 |
| Earth | #8A6A50 | 木・紙を連想する補助色。 |
| Season Accent | #D9A5AA | 蓮等の季節性を感じる淡いピンク。使用量は少なく。 |

## 8-4. Typography / UI / Layout

- 見出し：Noto Serif JP系。本文：Noto Sans JP系。読みやすさを優先し、装飾フォントの多用は避ける。

- CTA：濃いグリーンの塗りボタン＋細いアウトラインの副ボタン。角丸は4〜8px程度、強い影は使わない。

- 最大コンテンツ幅：約1120px。Desktopは2カラムを適度に使い、Mobileは1カラム。

- セクション余白：Desktop 96〜120px程度、Mobile 64〜80px程度を基準。

- 写真は4:5、3:2、16:9を役割ごとに固定し、カードごとの比率を混在させすぎない。

- アニメーションは軽いフェード／スライドアップのみ。パララックス・3D・複雑なスライダーは不要。

# 12. 写真・画像設計

## 12-1. 利用方針

- 営業サンプルでは、ユーザー確認済みの許可範囲内で公式Instagram写真を主要素材として活用する。

- Google Maps写真・第三者SNS写真はコピー／トレース／模写しない。

- 公式Instagramの共同投稿・転載・イベント出演者・外部講師等の画像は、第三者権利が関係する可能性があるため別途確認まで使用しない。

- 正式制作時は店舗から元画像を受領し、スクリーンショットではなく高解像度素材へ差し替える。
